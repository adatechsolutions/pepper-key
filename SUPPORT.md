# Support

## Community support

Use GitHub Issues for reproducible build, Flipper firmware, USB, browser, protocol-core, or relying-party compatibility problems. Include the PepperKey version/commit, capability ID from `capabilities.json`, official firmware/API, host OS/client version, expected behavior, and redacted steps.

A feature marked `implementation`, `research`, or `blocked` is not a support commitment. `core-ready` support covers published-vector source behavior only, not live device provisioning or account compatibility.

Never attach PepperKey app data, device identifiers, account details, recovery codes, authentication captures, or key material.

## Security reports

Use GitHub private vulnerability reporting. Do not open a public issue for a suspected vulnerability. See `SECURITY.md` for scope and safe-reporting rules.

## Commercial support

Ada Tech Solutions Inc. may offer scoped compatibility assessment, controlled deployment assistance, training, protocol engineering, and release qualification after the relevant capability's acceptance gate. Commercial support does not make PepperKey certified, suitable as a sole authenticator, or exempt from GPL source-distribution obligations.

Support availability, service levels, and pricing require a separate written agreement. No SLA is implied by the public repository or Apps Catalog listing.
