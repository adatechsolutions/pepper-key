# Support

## Community support

Use GitHub Issues for reproducible build, Flipper firmware, USB, browser, or relying-party compatibility problems. Include the PepperKey version, official firmware version, API version, host OS/browser version, expected behavior, and redacted steps to reproduce.

Never attach PepperKey app data, device identifiers, account details, recovery codes, authentication captures, or key material.

## Security reports

Use GitHub private vulnerability reporting. Do not open a public issue for a suspected vulnerability. See `SECURITY.md` for scope and safe-reporting rules.

## Commercial support

Ada Tech Solutions Inc. may offer scoped compatibility assessment, controlled deployment assistance, training, and release qualification after the public v0.1 acceptance gate. Commercial support does not make PepperKey certified, suitable as a sole authenticator, or exempt from GPL source-distribution obligations.

Support availability, service levels, and pricing require a separate written agreement. No SLA is implied by the public repository or Apps Catalog listing.
